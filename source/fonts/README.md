# Licensed fonts

Mercer's CSS declares slots for the Financial Times pairing from Klim Type Foundry:

| Slot | File to drop in here |
|---|---|
| Financier Display Light (headings) | `FinancierDisplay-Light.woff2` |
| Metric Regular (body) | `Metric-Regular.woff2` |
| Metric Medium (labels, buttons) | `Metric-Medium.woff2` |

Buy the web licences at klim.co.nz/retail-fonts/financier-display/ and klim.co.nz/retail-fonts/metric/,
put the three files in this folder, and republish. Until then the page falls back to Newsreader
(headings) and Figtree (body) from Google Fonts. Nothing else changes.
